# 실습

이 강좌의 실습은 대부분 **터미널 명령**이에요. 주차 폴더마다 `README.md`(단계별 명령과 "이렇게 나오면 성공" 화면)와 예제 파일(Dockerfile, compose.yaml, 셸 스크립트, 작은 파이썬 앱)이 있어요.

| 표시 | 뜻 |
|---|---|
| WSL | Windows 의 WSL2 Ubuntu(또는 Mac 터미널)에서 |
| Docker | Docker 가 깔린 내 PC 에서 — 못 깔면 무료 웹 실습장 안내를 따라요 |
| GitHub | 무료 GitHub 계정이 필요해요 |

각 주차 쪽의 "직접 해보기" 절에 그 주의 실습 폴더 링크가 있어요.
